我是 Cursor 的长期用户，最近 OpenAI 的 Codex 用得多。

20 美元每月不够用，100 美元每月又奢侈。于是我又补了一份 Claude Code 订阅。

加上公司给配的 CodeBuddy，我一个不写测评的开发者，意外凑齐了市面上主流的 AI 编程终端。

短暂可用的Fable 5 给我留下深刻的印象，于是我逐步删掉了一些文章和笔记，即便日后我再次遇到，AI也能轻松回答相关问题。

回顾之前对其他家模型的使用，我觉得这个时间点很适合写一篇主观性评测。

跑分榜大家都会看，这里我通过我持续的测试讨论下：跑分的水分、模型优势的连续性、模型公司的定局。

## 测试

:::tip
在个人代理通用任务上和编程场景中，下面的榜单已经连续6个月与我实际测试的一致，以后里程碑式的模型我会自己测，其他的我会采信跑分榜的结果。

- [https://artificialanalysis.ai/leaderboards/models](https://artificialanalysis.ai/leaderboards/models)
- [https://artificialanalysis.ai/agents/coding-agents](https://artificialanalysis.ai/agents/coding-agents)
:::

以下是我的部分真实任务的对照。提示词相同、环境相同，用 git 回退保证起点一致。

**任务一：系统 bug**

```md
我的微信截图无法正常使用，无报错，帮我排查，请先充分思考并获取足够的信息再开始排查
```

Claude Code 主动追问了两件事——「问题表现」和「首次出现时间」。诊断结果是：当前屏幕缩放比例为 166%，非 100% 整数倍导致截图坐标计算异常。调整为 100% 整数倍后修复，耗时 3m52s。

用 git 把环境重置，再让 Codex 处理。它没有先问，而是先要权限——读目录、读注册表、读日志，三次申请之后给出同样的修复路径，耗时 4m09s。

时间差不大，姿态完全不同：Claude Code 先问人、再动手；Codex 先动手、边动手边申请。这种差异在大型项目里会被放大——这是后面「思考」一章要展开的。

**任务二：文学风格**

```md
读取我的个人博客，生成我的写作风格摘要
```

这个任务只有 Opus 能完成。其余模型要么读不全归档页，要么把「读取博客」理解成「基于训练数据猜测博主风格」——前者是工具能力，后者是模型理解。不展开细节。

Opus 不是 benchmark 上最强的模型，但在「读懂人」这件事上独走。如果你只看跑分选工具，会错过这种差异。这也是为什么标题里写的不是"选最强"。

**任务三：API调整**

```md
读取我的项目接口文档，增加一个仅更新文章Hash数据的接口，先思考后完成。
```

这个任务 Opus 和 GPT 都完成了，但是修改都非常的多，极大的增加了项目的复杂度。

我自己的修改在去掉注释后，不到10行。

## 网络

**在公司**——出于数据安全和网络限制，能稳定用的只有 CodeBuddy 和 Cursor，二者都提供终端命令行工具和 IDE。

- CodeBuddy 合规、稳定，内置 `GLM-5.2`、`DeepSeek-V4-Pro` 等头部开源模型，对国内企业友好：采购合规，国产模型可用性也很好。
- Cursor 在大陆能用的模型只有三类：Grok 系、Kimi、Composer 2.5。

**在境外**——在台北这样的网络环境下，OpenAI 和 Anthropic 的模型比开源模型领先 3 ~ 12 个月。

Cursor 在境外没有模型限制，GPT、Opus、Gemini 各家顶级模型都能直接选。但 Grok 和 Gemini 不能设思考深度，达不到最佳状态，唯一优势是可以在 Opus 和 GPT 之间自由切换且没有滚动额度。

网络和合规让大规模的国外AI普及变得困难，这给了国内模型占领企业和高校AI实验室的机会。

## 思考

深度思考的模型会带来更好的编程体验，但也会带来更高的成本。

在 Cursor 里，Grok 和 Gemini 不能设思考深度，思考时长非常短。对于编程任务，模型如果不能在动手前充分推理，工程师就得反过来把指令拆得足够细——这等于退回了 2023 年 Copilot 时代的写法。

所以即使 Cursor 在境外不限制模型，我的主力依然只用 Opus 和 GPT，且都开到最大思考深度。

模型在编程上的能力排序，按这几年的体感：

> 后训练质量 + 参数量 > 思考深度 > 上下文长度 > 多模态

参数量是天花板，后训练决定能不能把天花板用满。但参数和后训练都到位之后，最后能不能完成复杂任务，看的就是模型在回答前自我思考的程度——也就是 thinking 这一档能不能拉满。

我对下一代模型的预估：随着 10T 参数量的 Grok 出现，结合 Cursor 团队的后训练，深度思考的 Grok 5 大概能追到 GPT 5.x 现在的水平。

但这只是技术线。技术线再领先，也回答不了下一个问题：你拿这家的模型，能做什么、不能做什么。

## 叙事

伊索寓言里有一则：猎狗追兔，追了半天没追上。牧羊人在旁边笑，猎狗回头说：我是为一顿饭在跑，它是为命在跑。

AI 公司的战略形态，就是这一句话的展开。

**兔子——AI 就是命。**

没有母业务兜底。模型在一条线上登不了顶，叙事和估值很快会消失。

所以兔子的姿态只有一种：**收缩到能赢的那条线，砍掉打不赢的。**

- Anthropic 砍图砍视频，所有算力压在 reasoning 和 coding 上
- OpenAI 关 Sora，守住文本和图像的头部位置。
- DeepSeek 不碰多模态，靠「便宜 + 推理强」融资
- Kimi 押长上下文，同样不碰图像视频
- 智谱（GLM）是兔子里最累的一只——想登顶但不敢砍，CogView、CogVideoX 全做、全在中段，但是目前也租要更新纯文本到文本的推理模型。

**猎狗——AI 是给主业加 buff。**

抖音、TikTok、搜索、电商、云、X 平台——母业务都在赚钱。AI 做不到第一不要紧，但缺一项就等于把场景送人。

所以猎狗的姿态也只有一种：**全栈、自研、每项中上即可。**

- Google 必须保搜索——Gemini 全线均衡、每条都挤进前列，但谁也不独走
- 字节有抖音和剪映——豆包做文本，Dreamina、Seedance 攻图攻视频，第三名就够反哺业务
- 阿里有电商和云——Qwen 全栈自研，保的是云客户不被卡脖子
- xAI 有 Tesla、SpaceX 兜底，X 平台做分发——Grok 跟热点跑量，叙事靠 Musk 本人

落到选型：

- 想体验某条线最强的模型 → 选兔子公司
- 想要一个全家桶覆盖所有 AI 功能 → 选猎狗公司

## 代价

工具之外要看商业模式。Cursor 最大的问题是它本质上是某种中转站。手动选择 `claude-sonnet-4.5`，实际拿到的却是 `Claude 3.5 Sonnet`是他的黑历史。加上它的 Harness 层是通用的，相同模型的调用效果通常不如原生：Opus 在 Cursor 里的体感明显弱于 Claude Code + Opus 。

至于自研 Composer 就是开源模型微调——这都算商业行为。但有一条规律值得记住：Cursor 订阅不支持退款，月费比年费安全。

ChatGPT 网页端降智也是亲身经历，有段时间文生图的质量极度不符。原因和 Cursor 偷换差不多——一个烧钱但只赚眼球不赚钱的功能，会被切换到更差的模型，或者缩短 GPU 推理时长，而不是排队等待。

Token 的盈利模式，最终变得和流量卡一样：无限流量的意思就是到某个用量后开始限速。

订阅制下，你用得越多它亏得越多。一旦超过厂商能承受的亏损线，就会出现各种异常。API 模式反过来——用得越多厂商赚得越多，直连通常不会异常，但费用控制不住，对我来说通常是包月价格的 5 倍。

## 退场

**公司核心项目里改功能、动业务逻辑——AI 一个字都不写。**

不是不信任模型，是不信任不知道项目历史的模型。

**纯个人提效工具——AI 全写，我一行不看。**

不对外开放，只看效果。能跑、对了就归档；下次坏了重提示一次即可。这类代码没有用户、没有维护负担，本质上是双向门——错了重来零成本。

**公司新功能的论证阶段——AI 写、我审核。**

这一档要的不是代码质量，是能不能跑出来给老板演示。审核一遍是为了一旦决定继续，不用从零重构。双向门 + 演示压力，是 AI 介入度最微妙的一档。

三档加在一起，AI 真正参与决策的代码就被压到了 10% 以下——而这 10% 全在中间那一档。

工具越强，反而越要主动决定哪一档归自己、哪一档归 AI。强工具能放大决策，也能放大失误。

模型仍然在变强。未来 18 个月，参数会更大、思考会更深、价格会更乱、厂商会换队形。但有一件事会越来越确定：**工具越强，越要靠人去决定它该干什么、不该干什么。**

当年编译器和高级编程语言大幅降低了软件开发门槛，使开发效率提升了一个数量级，是软件产业繁荣的关键基础之一。

AI对软件开发的提升同样是数量级的，我很期待看到未来人人会编程的时代，全世界的人从繁重的重复劳动中解放出来，去改进现状，发现新机会。

不过最大的阻碍是并不是技术本身是否能持续发展，而是人对创造的热情。

就像AI早就可以写歌了，并且质量相当不错，但是依然只有热爱音乐的人才会高强度的使用。
