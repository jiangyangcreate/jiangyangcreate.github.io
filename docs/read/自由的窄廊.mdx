:::tip
达龙·阿西莫格鲁与詹姆斯·罗宾逊的《自由的窄廊》是一部关于国家、社会与自由命运的作品。它提出：自由并不天然存在，只有当国家与社会同时足够强大、彼此制衡时，自由才可能出现；这条狭窄的平衡地带，就是书名所称的「窄廊」。

本书出版于 2019 年，英文书名是 *The Narrow Corridor*。其分析跨越历史与地域，用大量案例说明自由如何诞生、维持，又如何轻易失落。
:::

:::warning
《自由的窄廊》涉及国家权力、威权与民主等议题，论证偏理论且案例密集，阅读需要一定耐心。书中对部分国家与历史路径的判断也可能引发争议，建议结合自身背景批判性阅读。
:::

:::info
作者：达龙·阿西莫格鲁、詹姆斯·罗宾逊
:::

## 书籍摘要

自由是稀有的。国家和社会都很强时，自由才会存在。窄廊就是这种平衡出现的区域。国家离开窄廊，自由就会减少。

### 关键术语

- **国家：**制定并执行规则的一组制度。
- **社会：**公民、各类团体和社会规范。
- **利维坦：**本书对国家的称呼。国家可以强，也可以弱。

### 1. 缺席的利维坦

国家弱。没有中央权威执行规则。暴力和社会规范控制人。一些无国家社会和失败国家是例子。

### 2. 专制的利维坦

国家强，社会弱。国家控制人。人不能控制国家。中国的长期国家传统是本书的主要例子。现代威权国家也走这条路径。

### 3. 被束缚的利维坦

国家和社会都很强。社会监督国家，并限制国家的权力。国家提供安全和公共服务。这就是窄廊。许多西方民主国家处在这个区域。

本书用美国说明窄廊的一部分情况。美国在国家层面走进窄廊。美国社会在早期就有组织能力。联邦国家起初较弱。窄廊也可以在地方失败。密苏里州弗格森是一个例子。当地政府用罚款和警察力量支配黑人社区。当地黑人社区当时缺少社会权力，不能约束当地政府。

## 红皇后效应

刘易斯·卡罗尔写过红皇后。红皇后必须一直跑，才能留在原地。本书借用这个说法。

国家和社会必须互相竞争。每一方都要变得更强，才能制衡另一方。一方停止前进，平衡就会打破。自由不是固定的结果。自由需要持续的努力。

## 另外两个概念

- **纸面利维坦：**国家在纸面上有法律，但不能执行法律。精英无视规则。
- **规范之笼：**强大的社会规范把人锁在固定位置上。没有专制者，这些规范也会限制自由。种姓制度是一个例子。

在本书的印度案例里，种姓规则强于国家。国家打不破规范之笼。规范之笼也会控制国家。红皇后效应在这里中断。
